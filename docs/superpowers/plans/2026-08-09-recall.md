# Recall Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** New `apps/recall` monorepo sibling: admin uploads videos + YouTube links; transcripts are chunked/embedded into CE's pgvector; a public site searches and chats over them with second-exact YouTube deep links.

**Architecture:** Single public SPA + one authored BFFless proxy rule set. Ingest is staged (presigned upload → WhisperX transcribe job → chunk/embed/`embed_store` index job), with the transcript persisted on the video's `recall_videos` record so indexing is fully server-side. Publishing **is** indexing (drafts have zero embeddings, so the schema-wide rag-search chat tool cannot leak them). Public search = query-embed + `vector_search`; public chat = `ai_handler` (Haiku 4.5, SSE) + the `rag-search` plugin.

**Tech Stack:** React 19 + Vite + TS + Tailwind v4 + RTK Query (Studio's stack), BFFless pipelines (`presigned_upload`, `replicate`, `embed_store`, `vector_search`, `ai_handler`), Replicate WhisperX + `nateraw/bge-large-en-v1.5`, Vitest.

## Global Constraints

- Work on a feature branch (`feat/recall`) in an isolated worktree (`superpowers:using-git-worktrees`); **never commit to `main`**; push every commit before opening the PR (user merges fast).
- Workspace git rules apply: ask the user before the first commit/push; PR title must be a conventional commit (squash → it becomes the release commit).
- App must pass `pnpm apps:check`: authored rule set only (a raw `bffless/<app>.proxy-rules.json` is a hard CI failure), `bffless/README.md` with headings `Manual setup (admin panel)` and `First-success checkpoint`.
- Rule-authoring format: `ruleset.yaml` + `rules/<path>/<method>/rule.yaml` + sibling `*.fn.js` (`code: ./x.fn.js`) + `schemas/*.schema.yaml` referenced as `$schema:<name>`. Build check: `npx bffless rules build apps/recall/.bffless/proxy-rules/recall -o /tmp/recall.json`.
- Every admin rule: `validators: [{type: auth_required, config: {roles: ['admin']}}]`. Public AI rules: `rate_limit` keyed by ip.
- No request body may approach 1 MB (edge nginx cap): large payloads go presigned-to-bucket or stay server-side via `data_query`.
- Storage paths in fn handlers are always `deployment.owner + '/' + deployment.repo + '/uploads/' + key` — never hard-coded (catalog portability).
- Embedding model is pinned: `nateraw/bge-large-en-v1.5`, used identically at ingest and query. Chunk text carries an inline `[t=<sec>s] ` prefix (interim timestamp carrier until the CE patch is deployed).
- No base64/blobs in Redux or localStorage; video `File`s and blob URLs are transient React state.
- `2147483648` (2 GiB) max upload size; `maxFileSize` on every upload rule; client validates MIME + size before uploading.
- Frontend files: match Studio's idioms (RTK Query with 401→refresh→retry base query, `fetchWithReauth` for prepare/register, plain `fetch` with no credentials for bucket PUTs).
