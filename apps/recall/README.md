# Recall

Video transcript RAG search & chat — search across your video transcripts and chat with an AI
that cites the moments it found.

Recall is a static app with no server. Every backend step is a BFFless pipeline running on your
own instance, so you bring the credentials. This is the scaffolding-only version of the app
(bffless/apps Task 2) — no features are implemented yet.
